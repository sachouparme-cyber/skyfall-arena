# skyfall-arena

Battle royale 3D game.

This project is intended to run as a static web page served by GitHub Pages.

Preview:
https://sachouparme-cyber.github.io/skyfall-arena/

Files:
- index.html — main game page
- README.md — project description

To use GitHub Pages:
1. Go to Settings > Pages
2. Set Source to "Deploy from a branch"
3. Select branch: main
4. Select folder: / (root)
5. Save

This README is intentionally kept short so GitHub Pages can serve the real game from index.html.
